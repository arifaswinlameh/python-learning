# Python Learning

Repositori ini berisi kumpulan proyek dan implementasi praktis menggunakan Python, dengan fokus pada penulisan kode yang terstruktur, mudah dibaca, dan mudah dipelihara.

## Tentang Repositori

Repositori ini dibuat sebagai tempat untuk mengembangkan kemampuan pemrograman Python melalui berbagai proyek dan eksperimen. Setiap proyek disusun dalam direktori tersendiri agar kode sumber dan dokumentasinya lebih terorganisasi.

Selain sebagai tempat penyimpanan kode, repositori ini juga menjadi sarana untuk menerapkan konsep pemrograman, melatih kemampuan pemecahan masalah, dan mengeksplorasi berbagai penerapan Python.

## Teknologi yang Digunakan

- **Bahasa pemrograman:** Python
- **Editor kode:** Visual Studio Code
- **Version control:** Git dan GitHub

## Menjalankan Program

Untuk menjalankan program, masuk ke direktori proyek yang diinginkan dan ikuti petunjuk penggunaan yang tersedia pada README proyek tersebut.

Pastikan Python telah terpasang dan dikonfigurasi dengan benar pada sistem.
