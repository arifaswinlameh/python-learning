# Student Grade Manager

Program terminal sederhana untuk mengelola data dan nilai mahasiswa menggunakan Python.

## Features
- Menambahkan data mahasiswa beserta tiga nilai ujian.
- Menampilkan data mahasiswa dan nilai ujian.
- Menghitung rata-rata nilai mahasiswa.
- Menentukan status kelulusan berdasarkan rata-rata nilai.
- Mencari mahasiswa dengan rata-rata nilai tertinggi.
- Menu interaktif untuk mengakses fitur program.

## Passing Criteria
- Rata-rata nilai ≥ 75: Lulus.
- Rata-rata nilai < 75: Tidak Lulus.

## How to Run

```bash
python main.py
```

## Concepts Used
- Functions
- Lists and dictionaries
- Loops and conditionals
- Tuples
- `match-case`

## Limitations
Data mahasiswa hanya disimpan selama program berjalan dan tidak disimpan secara permanen.
